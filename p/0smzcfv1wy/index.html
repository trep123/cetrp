分解实验12：防火墙配置

2026-10-11Network / Huawei#软考#网络工程师#华为#防火墙

本实验在 eNSP 的 USG6000V 防火墙上完成接口与安全区域划分、安全策略、源 NAT（地址池 100.1.1.10-100.1.1.20）和 NAT Server 端口映射，让内网 PC 访问 Internet，并让 Internet 通过公网地址访问 DMZ 中的 Web 服务器。

2、配置要求

  1. 防火墙接口的 IP 地址如拓扑所示，将接口划入相应的安全区域。
  2. 内网主机 PC1 可以主动访问 Internet，但 Internet 无法主动访问 PC1。
  3. 出口防火墙进行 NAT，NAT 公网地址池 100.1.1.10-100.1.1.20。
  4. Internet 可以通过公网地址 100.1.1.100/24 访问目的地址为 192.168.2.100/24 的内部 Web 服务。

3、配置步骤

第 2 步：配置防火墙接口 IP 地址

（1）防火墙接口 IP 配置

[FW] interface GigabitEthernet1/0/1
[FW-GigabitEthernet1/0/1] ip address 192.168.1.254 24
[FW] interface GigabitEthernet1/0/2
[FW-GigabitEthernet1/0/2] ip address 192.168.2.254 24
[FW] interface GigabitEthernet1/0/3
[FW-GigabitEthernet1/0/3] ip address 100.1.1.1 24

注意：原文接口视图提示符写作 [FW-GigabitEthernet0/0/1]、[FW-GigabitEthernet0/0/2]、[FW-GigabitEthernet0/0/3]，与所进入的接口 GigabitEthernet1/0/1～1/0/3 不一致，这里按 1/0/x 修正。另外，上一步把设备命名为 Firewall，原文后续命令的提示符有时写作 [FW]、有时写作 [Firewall]，指的是同一台防火墙，下文保留原文写法。

（2）Internet 设备接口 IP 配置（用路由器模拟）

<Huawei> system-view
[Huawei] sysname Internet
[Internet] interface GigabitEthernet0/0/0
[Internet-GigabitEthernet0/0/0] ip address 100.1.1.2 24

（3）配置 PC1 和 Server 的 IP 参数

原图为 eNSP 中 PC1 和 Server 的“基础配置”界面截图，参数如下：

设备 IP 地址 子网掩码 网关 其他
PC1 192.168.1.1 255.255.255.0 192.168.1.254 IPv4 静态配置，MAC 54-89-98-CE-5C-66，DNS 0.0.0.0
Server 192.168.2.100 255.255.255.0 192.168.2.254 MAC 54-89-98-E6-0F-3F，域名服务器 0.0.0.0

第 3 步：把防火墙接口加入相应安全域

[FW] firewall zone trust
[FW-zone-trust] add interface GigabitEthernet1/0/1
[FW] firewall zone dmz
[FW-zone-dmz] add interface GigabitEthernet1/0/2
[FW] firewall zone untrust
[FW-zone-untrust] add interface GigabitEthernet1/0/3

第 4 步：配置安全策略，让 trust 区域（192.168.1.0/24）可以访问 Internet

[FW] security-policy //进入安全策略配置
[FW-policy-security] rule name trust_to_untrust
[FW-policy-security-rule-trust_to_untrust] source-zone trust
[FW-policy-security-rule-trust_to_untrust] source-address 192.168.1.0 mask 255.255.255.0
[FW-policy-security-rule-trust_to_untrust] destination-zone untrust
[FW-policy-security-rule-trust_to_untrust] action permit

注意：原文最后一行的提示符写作 [FW-policy-security-rule-policy_sec_deny1]，与本规则名 trust_to_untrust 不一致，这里按 trust_to_untrust 修正。

第 5 步：NAT 配置

上述配置虽然放通了 192.168.1.0/24 访问 Internet 的流量，但是由于 192.168.1.0/24 是私有 IP 地址，不能直接进入公网，因此为了让内网用户能够访问公网，还必须配置 NAT。

（1）配置 NAT 地址池，开启端口转换。

[Firewall] nat address-group addressgroup1
[Firewall-address-group-addressgroup1] mode pat
[Firewall-address-group-addressgroup1] section 0 100.1.1.10 100.1.1.20
//地址池编号是0，包含可用公网IP地址从100.1.1.10到100.1.1.20，共11个地址
[Firewall-address-group-addressgroup1] quit
[Firewall]

（2）配置源 NAT 策略 1，实现私网指定网段访问 Internet 时自动进行源地址转换。

[FW] nat-policy
[FW-policy-nat] rule name policy_nat1
[FW-policy-nat-rule-policy_nat1] source-zone trust
[FW-policy-nat-rule-policy_nat1] destination-zone untrust
[FW-policy-nat-rule-policy_nat1] source-address 192.168.1.0 24
[FW-policy-nat-rule-policy_nat1] destination-address any
[FW-policy-nat-rule-policy_nat1] action source-nat address-group addressgroup1 //采用源地址NAT，把192.168.1.0/24转换为addressgroup1的公网地址

第 10 步：配置服务器端口映射。

下面的命令，将内部 IP 地址 192.168.2.100 的 80 端口映射到了公网地址 100.1.1.100 的 80 端口，当公网用户访问 100.1.1.100 的 80 端口服务时，自动跳转到内部服务器 192.168.2.100 的 80 端口。

（1）配置安全策略，允许外部网络用户访问 DMZ 区域的 Web 服务器网段。

[FW] security-policy
[FW-policy-security] rule name untrust_to_dmz
[FW-policy-security-rule-untrust_to_dmz] source-zone untrust
[FW-policy-security-rule-untrust_to_dmz] destination-zone dmz
[FW-policy-security-rule-untrust_to_dmz] destination-address 192.168.2.0 24
[FW-policy-security-rule-untrust_to_dmz] action permit

注意：原文规则视图提示符写作 [FW-policy-security-rule-policy1]，与所建规则名 untrust_to_dmz 不一致，这里按 untrust_to_dmz 修正。

（2）配置 NAT Server 功能，把内网 Web 服务映射到公网地址。

[FW] nat server policy_web protocol tcp global 100.1.1.100 80 inside 192.168.2.100 80

第 11 步：验证端口映射是否成功，Internet 可以正常访问内部 Web 服务器。

注意：原文此处步骤号写作“第 10 步”，与上一步重复，这里顺延为第 11 步。

分解实验03：NAT原理及应用

2026-10-11Network / Huawei#软考#网络工程师#华为#NAT

本实验先介绍 NAT 的技术背景和 RFC1918 私网地址段，再在出口路由器 RT1 上依次配置静态 NAT、动态 NAT、NAPT、Easy IP 和 NAT Server 五种地址转换方式。

一、技术背景与原理

随着互联网用户的增多，IPv4 公有地址资源短缺，同时 IPv4 公有地址资源存在地址分配不均的问题，这导致部分地区的 IPv4 可用公有地址严重不足。为解决该问题，使用过渡技术 NAT 解决 IPv4 公有地址短缺。内网可以使用 RFC1918 定义的私有地址，访问互联网时通过 NAT 网络地址转换技术将私网 IP 转换成公网 IP。下面就是 RFC1918 定义的私网地址段：

A类：10.0.0.0 ~ 10.255.255.255 
B类：172.16.0.0 ~ 172.31.255.255
C类：192.168.0.0 ~ 192.168.255.255

二、5 种 NAT 类型

五种类型共用同一套拓扑：三台内网 PC 和Server接到出口路由器 RT1（NAT 设备）内网接口，RT1 经 Internet 连到外网 。

设备 接口 IP/掩码 设备 接口
Cient1 G1/0/0 192.168.1.1/24 RT1 G0/0/2
Client2 G1/0/0 192.168.1.2/24 RT1 G0/0/3
Server G1/0/0 192.168.1.3/24 RT1 G0/0/1
RT1 G0/0/0 12.1.1.1/24 Internet eth1 
 私有网络
 PC1 192.168.1.1/24 ─┐
 PC2 192.168.1.2/24 ─┼─[SW]── 192.168.1.254 [R1/NAT] 12.1.1.1/24 ── Internet ── Web服务器 12.1.1.254/24
 PC3 192.168.1.3/24 ─┘

1、静态 NAT

静态 NAT：将内网主机的私网 IP 地址一对一映射到公网 IP 地址。

图 静态 NAT 原理中的 NAT 映射表：

私有地址 公有地址
192.168.1.1 12.1.1.2
192.168.1.2 12.1.1.3
192.168.1.3 12.1.1.4

在 R1 上配置静态 NAT 将内网主机的私有地址一对一映射到公有地址。

[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] ip address 12.1.1.1 24
[R1-GigabitEthernet0/0/1] nat static enable //开启静态NAT功能
[R1-GigabitEthernet0/0/1] nat static global 12.1.1.2 inside 192.168.1.1
[R1-GigabitEthernet0/0/1] nat static global 12.1.1.3 inside 192.168.1.2
[R1-GigabitEthernet0/0/1] nat static global 12.1.1.4 inside 192.168.1.3
//配置1对1地址转换关系，其中路由器接口地址不能用，不然会提示冲突。

2、动态 NAT

动态 NAT：将内网主机的私有地址转换为公网地址池里面的地址。由于静态 NAT 严格地一对一进行地址映射，这就导致即便内网主机长时间离线或者不发送数据时，与之对应的公有地址也处于使用状态。为了避免地址浪费，动态 NAT 提出了地址池概念：所有可用的公有地址组成地址池。当内部主机访问外部网络时临时分配一个地址池中未使用的地址，并将该地址标记为“In Use”。当该主机不再访问外部网络时回收分配的地址，重新标记为“Not Use”。

图中的 NAT 地址池（初始状态）：

公有地址 状态
12.1.1.2 Not Use
12.1.1.3 Not Use
12.1.1.4 Not Use

在 R1 上配置动态 NAT 将内网主机的私有地址动态映射到公有地址。

[R1] nat address-group 1 12.1.1.2 12.1.1.4 //配置NAT地址池，包含3个公网地址
[R1] acl 2000
[R1-acl-basic-2000] rule 5 permit source 192.168.1.0 0.0.0.255 //配置转换源地址
[R1-acl-basic-2000] quit
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] nat outbound 2000 address-group 1 no-pat //把ACL2000匹配的源地址转换为address-group 1定义的公网地址，no-pat表示不做端口转换。只能实现1：1转换，有多少个公网IP才能满足多少个私网终端上网。

3、NAPT

NAPT：也叫端口 NAT 或 PAT，从地址池中选择地址进行地址转换时不仅转换 IP 地址，同时也会对端口号进行转换，从而实现公有地址与私有地址的 1:N 映射，可以有效提高公有地址利用率，即 1 个公网 IP 地址可以用于多个私网终端的地址转换。

图 NAPT 原理图：NAT 地址池为 12.1.1.2、12.1.1.3、12.1.1.4，NAT 映射表如下。

私有地址:端口 公有地址:端口
192.168.1.1:10321 12.1.1.2:1025
192.168.1.2:17087 12.1.1.2:1026 
[R1] nat address-group 1 12.1.1.2 12.1.1.4 //配置NAT地址池，包含3个地址
[R1] acl 2000
[R1-acl-basic-2000] rule 5 permit source 192.168.1.0 0.0.0.255 //配置转换源地址
[R1-acl-basic-2000] quit
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] nat outbound 2000 address-group 1 //把ACL2000匹配的源地址转换为address-group 1定义的公网地址，没有关键字no-pat，表示要做端口转换

注意：原文注释写作「ACL200」，应为 ACL2000。

4、Easy IP

Easy IP：特殊的 NAPT，Easy IP 没有地址池的概念，使用接口地址作为 NAT 转换的公有地址。Easy IP 适用于不具备固定公网 IP 地址的场景：如通过 DHCP、PPPoE 拨号获取地址的私有网络出口，可以直接使用获取到的动态地址进行转换。

图 Easy IP 原理图中的 NAT 映射表：

私有地址:端口 公有地址:端口
192.168.1.1:10321 12.1.1.1:1025
192.168.1.2:17087 12.1.1.1:1026

在 R1 上配置 Easy-IP 让内网所有私有地址转换为路由器接口地址 12.1.1.1 访问公网。

[R1] acl 2000
[R1-acl-basic-2000] rule 5 permit source 192.168.1.0 0.0.0.255
[R1-acl-basic-2000] quit
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] nat outbound 2000

5、NAT Server

NAT Server：将内部服务器映射到公网。在出口路由器 R1 上配置 NAT Server 将内网服务器 192.168.1.10 的 80 端口映射到公有地址 12.1.1.1 的 80 端口，外部互联网用户访问 12.1.1.1 的 80 端口，可以自动跳转访问内部 Web 服务器 192.168.1.10 的 80 端口。NAT Server 主要用于隐藏内部服务器，保障网络安全。

NAT Server 拓扑：

设备 接口 / 位置 IP/掩码 角色
Web 服务器 私有网络 192.168.1.10 内网服务器
R1 内网侧接口 192.168.1.254 内网网关
R1 G0/0/1（公网侧） 12.1.1.1 NAT Server
外网 PC Internet 侧 12.1.1.254/24 外部访问者 
 Web服务器 192.168.1.10 ──[SW]── 192.168.1.254 [R1/NAT Server] 12.1.1.1 ── Internet ── PC 12.1.1.254/24

图中的 NAT 映射表：

私有地址:端口 公有地址:端口
192.168.1.10:80 12.1.1.1:80

NAT Server 配置：

[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] ip address 12.1.1.1 24
[R1-GigabitEthernet0/0/1] nat server protocol tcp global 12.1.1.2 80 inside 192.168.1.10 80 //把内网192.168.1.10的80端口映射到12.1.1.2的80端口

提示：原文此处前后不一致——文字说明和映射表用的公网地址是 12.1.1.1:80，而配置命令和注释用的是 12.1.1.2:80。这里按原图保留命令原样，做题时以题目给出的公网地址为准。

三、总结

  • 静态 NAT：将内网主机的私有地址一对一映射到公有地址。
  • 动态 NAT：将内网主机的私有地址转换为公网地址池里面的地址。
  • NAPT：也叫端口 NAT 或 PAT，从地址池中选择地址进行地址转换时不仅转换 IP 地址，同时也会对端口号进行转换，从而实现公有地址与私有地址的 1:N 映射，可以有效提高公有地址利用率。
  • Easy-IP：特殊的 NAPT，Easy IP 没有地址池的概念，使用设备接口地址作为 NAT 转换的公有地址。
  • NAT Server：将内部服务器映射到公网，保障服务器安全。

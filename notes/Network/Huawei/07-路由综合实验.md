# 分解实验07：路由综合实验

本实验在 AS100 内部用 RIPv2 实现互通，在 R3、R4、R5 之间建立 eBGP 和 iBGP 邻居，再通过 R3 上的双向路由引入和 R4 上的 next-hop-local，让 AS100 的 PC1 与 AS200 的 PC2 正常通信；最后把 AS100 的 RIP 换成 OSPF 继续测试。

<!-- more -->

## 1、实验需求

1. 配置 RIPv2 和 BGP 分别实现 AS100 和 AS200 内部互通；
2. 让处于 BGP AS100 的 PC1 可以与 BGP AS200 中的 PC2 正常通信。

| R1 | GE0/0/0 | 100.1.1.254/24 | AS100，PC1 的网关 |
| R1 | GE0/0/1 | 12.1.1.1/30 | AS100，连 R2 |
| R1 | GE0/0/2 | 13.1.1.1/30 | AS100，连 R3 |
| R2 | GE0/0/1 | 12.1.1.2/30 | AS100，连 R1 |
| R2 | GE0/0/2 | 23.1.1.1/30 | AS100，连 R3 |

| R3 | GE0/0/2 | 23.1.1.2/30 | AS100，连 R2 |
| R3 | GE0/0/0 | 34.1.1.1/30 | AS100 边界，eBGP 连 R4 |
| R4 | GE0/0/0 | 34.1.1.2/30 | AS200 边界，eBGP 连 R3 |
| R4 | GE0/0/1 | 45.1.1.1/30 | AS200，iBGP 连 R5 |
| R5 | GE0/0/1 | 45.1.1.2/30 | AS200，iBGP 连 R4 |

```text
          BGP AS 100（RIP 或 OSPF）                         BGP AS 200
   R2 .2 GE0/0/1 ---- 12.1.1.0/30 ---- GE0/0/1 .1 R1

   R3 GE0/0/0 .1 ---- 34.1.1.0/30 (eBGP) ---- .2 GE0/0/0 R4
   R4 GE0/0/1 .1 ---- 45.1.1.0/30 (iBGP) ---- .2 GE0/0/1 R5

   PC1 100.1.1.1/24 ---- GE0/0/0 R1 (100.1.1.254/24)
   PC2 200.1.1.1/24 ---- GE0/0/0 R5 (200.1.1.254/24)
```

## 3、实验总体步骤

1. 根据规划配置 IP 地址。
2. 配置 AS100 中 RIPv2 路由协议，实现内部 AS100 内部互通；
3. 配置 eBGP 和 iBGP 对等体，建立 BGP 邻居；
4. 路由引入与网络优化；
5. 连通测试。

## 4、实验配置过程与命令

### Step 1：根据规划配置 IP 地址（略）

### Step 2：配置 AS100 中 RIPv2 路由协议，实现内部 AS100 内部互通

R1 配置 RIPv2：

```text
[R1] rip 1 //配置rip，进程号为1
[R1-rip-1] version 2 //配置RIPv2
[R1-rip-1] network 12.0.0.0 //宣告网段，RIP只能宣告主类网络号（A类地址默认主类网络号是/8，B类地址默认主类网络号是/16，C类地址默认主类网络号是/24）
[R1-rip-1] network 13.0.0.0
[R1-rip-1] network 100.0.0.0
```

R2 配置 RIPv2：

```text
[R2] rip 1
[R2-rip-1] version 2
[R2-rip-1] network 12.0.0.0
[R2-rip-1] network 23.0.0.0
```

R3 配置 RIPv2：

```text
[R3] rip 1
[R3-rip-1] version 2
[R3-rip-1] network 23.0.0.0
[R3-rip-1] network 13.0.0.0
```

### Step 3：配置 eBGP 和 iBGP 对等体，建立 BGP 邻居

> 注意：原文小标题写作「建议 BGP 邻居」，应为「建立 BGP 邻居」。

R3 上配置 eBGP 邻居：

```text
[R3] bgp 100 //启动BGP，指定本地AS号为100
[R3-bgp] peer 34.1.1.2 as-number 200 //配置R3和R4建立eBGP连接(或指定对等体的IP地址及其所属的AS编号)
```

R4 上配置 eBGP 和 iBGP 邻居：

```text
[R4] bgp 200 //启动BGP，指定本地AS号为200
[R4-bgp] peer 34.1.1.1 as-number 100 //配置R3和R4建立eBGP连接(或指定对等体的IP地址及其所属的AS编号)
[R4-bgp] peer 45.1.1.2 as-number 200 //配置R4和R5建立iBGP连接(或指定对等体的IP地址及其所属的AS编号)
```

R5 上配置 iBGP 邻居：

```text
[R5] bgp 200
[R5-bgp] peer 45.1.1.1 as-number 200
```

```text
[R3-bgp] ipv4-family unicast
[R3-bgp-af-ipv4] import-route rip 1 //把RIP路由引入BGP
```

如何解决上面的问题呢？其实很简单，只需要 R4 对外通告的时候把下一跳设置为自己即可，配置如下，一条命令搞定。

```text
[R4] bgp 200
[R4-bgp] ipv4-family unicast
[R4-bgp-af-ipv4] peer 45.1.1.2 next-hop-local //R4向对等体R5通告BGP路由时，把下一跳设置为自己的接口地址
```

配置完成后，BGP 收敛需要时间，可以等一会再查看路由表变化，也可以把接口 shutdown 再 undo shutdown，或者在用户模式下执行 reset bgp all，重置 BGP 进程，加速网络收敛。网络完成收敛后，BGP 路由中到达 100.1.1.0/24 的下一跳变为 45.1.1.1，这个地址是 R5 的直连路由，可达。

## 5、实验扩展：将 AS100 的 RIP 改为 OSPF

将 R1、R2、R3 运行的路由协议由 RIP 更改为 OSPF，继续测试。

R1 删除 RIP，配置 OSPF：

```text
[R1] interface g0/0/2
[R1-GigabitEthernet0/0/2] undo shutdown //把先前关闭的接口打开
[R1-GigabitEthernet0/0/2] quit
[R1] undo rip 1 //删除RIP
Warning: The RIP process will be deleted. Continue?[Y/N]y //y代表确认删除
[R1] ospf 1 //启用OSPF，进程号为1
[R1-ospf-1] area 0 //配置区域0
[R1-ospf-1-area-0.0.0.0] network 12.1.1.0 0.0.0.3 //宣告网段12.1.1.0/30
[R1-ospf-1-area-0.0.0.0] network 13.1.1.0 0.0.0.3 //宣告网段13.1.1.0/30
[R1-ospf-1-area-0.0.0.0] network 100.1.1.0 0.0.0.255 //宣告网段100.1.1.0/24
```

R2 删除 RIP，配置 OSPF：

```text
[R2] undo rip 1
Warning: The RIP process will be deleted. Continue?[Y/N]y
[R2] ospf 1
[R2-ospf-1] area 0
[R2-ospf-1-area-0.0.0.0] network 12.1.1.0 0.0.0.3
[R2-ospf-1-area-0.0.0.0] network 23.1.1.0 0.0.0.3
```

```text

[R3-ospf-1-area-0.0.0.0] network 23.1.1.0 0.0.0.3
[R3-ospf-1-area-0.0.0.0] network 13.1.1.0 0.0.0.3
```

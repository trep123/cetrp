# 分解实验08：路由策略

本实验中 R1 运行 RIPv2、R3 运行 OSPF，R2 在两者之间做双向路由引入，并通过 ACL 配合 route-policy：一是向 R1 通告 R3 的三个环回口时把 cost 设为 10，二是只让 R3 学到 10.1.2.0/24 和 10.1.3.0/24。

<!-- more -->

## 1、实验需求

1. 让 R3 可以学到 10.1.2.0/24 和 10.1.3.0/24 路由，不能学到 10.1.1.0/24。
2. 让 R2 向 R1 通告 R3 的三个环回接口，cost 设置为 10。

> 注意：原文需求 1 写作「10.1.1.3.0/24」，按拓扑应为 10.1.3.0/24。

## 2、网络拓扑

| 设备 | 接口 | IP/掩码 | 路由协议 / 角色 |
| --- | --- | --- | --- |
| R1 | GE0/0/0 | 12.1.1.1/30 | RIPv2 |
| R1 | LoopBack0 | 10.1.1.1/24 | RIPv2 |
| R1 | LoopBack1 | 10.1.2.1/24 | RIPv2 |
| R1 | LoopBack2 | 10.1.3.1/24 | RIPv2 |
| R2 | GE0/0/0 | 12.1.1.2/30 | RIPv2，边界路由器 |
| R2 | GE0/0/1 | 23.1.1.1/30 | OSPF，边界路由器 |
| R3 | GE0/0/1 | 23.1.1.2/30 | OSPF |
| R3 | LoopBack0 | 30.1.1.1/24 | OSPF |
| R3 | LoopBack1 | 30.1.2.1/24 | OSPF |
| R3 | LoopBack2 | 30.1.3.1/24 | OSPF |

```text
 Lo0 10.1.1.1/24                                                  Lo0 30.1.1.1/24
 Lo1 10.1.2.1/24                                                  Lo1 30.1.2.1/24
 Lo2 10.1.3.1/24                                                  Lo2 30.1.3.1/24
      R1 GE0/0/0 ---- 12.1.1.0/30 ---- GE0/0/0 R2 GE0/0/1 ---- 23.1.1.0/30 ---- GE0/0/1 R3
         .1          (RIPv2)               .2      .1           (OSPF)              .2
```

## 3、实验步骤

1. 配置 IP 地址
2. 配置 RIP 和 OSPF
3. R2 上配置路由引入和路由策略，进行路由过滤和 cost 设置
4. 验证测试

## 4、配置过程与命令

### Step 1：配置 IP 地址

R1 配置 IP 地址：

```text
<Huawei> system-view
[Huawei] sysname R1
[R1] int g0/0/0
[R1-GigabitEthernet0/0/0] ip address 12.1.1.1 30
[R1] int LoopBack 0 //启用环回接口0，环回口比较稳定，只要不手动shutdown就会一直up，经常用于测试或者OSPF router-id
[R1-LoopBack0] ip address 10.1.1.1 24
[R1] int LoopBack 1
[R1-LoopBack1] ip address 10.1.2.1 24
[R1-LoopBack1] quit
[R1] interface LoopBack 2
[R1-LoopBack2] ip address 10.1.3.1 24
```

R2 配置 IP 地址：

```text
<Huawei> system-view
[Huawei] sysname R2
[R2] int GigabitEthernet0/0/0
[R2-GigabitEthernet0/0/0] ip address 12.1.1.2 30
[R2-GigabitEthernet0/0/0] quit
[R2] int GigabitEthernet0/0/1
[R2-GigabitEthernet0/0/1] ip add 23.1.1.1 30
```

R3 配置 IP 地址：

```text
<Huawei> system-view
[Huawei] sysname R3
[R3] int g0/0/1
[R3-GigabitEthernet0/0/1] ip address 23.1.1.2 30
[R3-GigabitEthernet0/0/1] quit
[R3] interface LoopBack 0
[R3-LoopBack0] ip address 30.1.1.1 24
[R3-LoopBack0] quit
[R3] interface LoopBack 1
[R3-LoopBack1] ip address 30.1.2.1 24
[R3-LoopBack1] quit
[R3] interface LoopBack 2
[R3-LoopBack2] ip address 30.1.3.1 24
```

### Step 2：配置 RIP 和 OSPF

R1 配置 RIP 协议：

```text
[R1] rip 1
[R1-rip-1] version 2
[R1-rip-1] network 10.0.0.0
[R1-rip-1] network 12.0.0.0
```

R2 配置 RIP 和 OSPF：

```text
[R2] rip 1
[R2-rip-1] version 2
[R2-rip-1] network 12.0.0.0
[R2-rip-1] quit
[R2] ospf 1
[R2-ospf-1] area 0
[R2-ospf-1-area-0.0.0.0] network 23.1.1.0 0.0.0.3
```

R3 配置 OSPF：

```text
[R3] ospf 1
[R3-ospf-1] area 0
[R3-ospf-1-area-0.0.0.0] network 23.1.1.0 0.0.0.3
[R3-ospf-1-area-0.0.0.0] network 30.1.1.0 0.0.0.255
[R3-ospf-1-area-0.0.0.0] network 30.1.2.0 0.0.0.255
[R3-ospf-1-area-0.0.0.0] network 30.1.3.0 0.0.0.255
```

### Step 3：R2 上配置路由引入和路由策略，进行路由 cost 设置

```text
[R2] acl 2000
[R2-acl-basic-2000] rule 10 permit source 30.1.1.0 0.0.0.255
[R2-acl-basic-2000] rule 20 permit source 30.1.2.0 0.0.0.255
[R2-acl-basic-2000] rule 30 permit source 30.1.3.0 0.0.0.255
[R2] route-policy 10 permit node 10
Info: New Sequence of this List.
[R2-route-policy] if-match acl 2000
[R2-route-policy] apply cost 10
[R2] rip 1
[R2-rip-1] version 2
[R2-rip-1] import-route ospf 1 route-policy 10
```

R1 上查看从 R2 学到的 RIP 路由，开销是 11，即 R2 对外发布开销是 10，加上 R2 本身算 1 跳，最后开销就是 11，达到实验预期效果。

### Step 4：R2 上配置路由引入和路由策略，进行路由过滤

```text
[R2] acl 2001
[R2-acl-basic-2001] rule 10 permit source 10.1.2.0 0.0.0.255
[R2-acl-basic-2001] rule 20 permit source 10.1.3.0 0.0.0.255
[R2-acl-basic-2001] quit
[R2] route-policy 20 permit node 20
Info: New Sequence of this List.
[R2-route-policy] if-match acl 2001
[R2] ospf 1
[R2-ospf-1] import-route rip route-policy 20
```

R3 上查看路由学习情况，通过路由策略过滤，R3 只学到了 10.1.2.0/24 和 10.1.3.0/24，没有学到 10.1.1.0/24，实验成功！
